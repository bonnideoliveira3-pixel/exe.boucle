# Site d'artiste : Odile Marsan (artiste imaginaire)

Ouvre `index.html` dans ton navigateur (double-clic), ou dans VS Code installe l'extension **Live Server** puis clic droit sur `index.html` → *Open with Live Server*.

| Fichier | Rôle |
|---|---|
| `index.html` | Le contenu : les textes et les sections de la page |
| `style.css` | L'apparence : couleurs, polices, tailles, disposition |
| `script.js` | Ce qui bouge : liste des titres, concerts, pochette dessinée, extraits audio, formulaire |

## Modifier facilement
- **Couleurs** : en haut de `style.css`, change `--accent`, `--fond`…
- **Morceaux et concerts** : en haut de `script.js`, les listes `titres` et `concerts`.
- **Textes (bio, accroche)** : directement dans `index.html`.
